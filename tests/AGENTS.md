# Tests — AGENTS.md

## Role and authoritative guidance

The suite covers scientific numerics, manuscript invariants, maintenance behavior and rendering/integration contracts. [Testing guide](../docs/testing_guide.md) owns real nodes, execution recipes, configured omissions and permitted isolation; do not maintain a duplicate mutable inventory here.

The 90% gate applies to the branch-enabled reported total with configured omissions, not separate line and branch floors or proof of complete API/scientific coverage. Run from the standalone project root using the locked setup and commands in [pipeline guide](../docs/pipeline_guide.md).

## Conventions and limits

Use real scientific algorithms and numerical inputs. Filesystem/environment/failure isolation follows the testing guide; do not replace scientific behavior with mocks. Headless plotting uses `Agg`; native Mermaid checks require the actual admitted toolchain. Optional snippet execution and prerequisite resolution do not establish exhaustive lab execution or prerequisite acyclicity.

Add focused behavioral tests beside the relevant subsystem. Re-read actual test definitions before documenting node IDs. Mermaid metadata normalization and assessment dry-run behavior are the scope of `test_script_quality.py`, not an imaginary script-hygiene inventory.

[Manuscript instructions](../docs/manuscript/AGENTS.md) own H1s, IDs, reference types and authored assessment preservation; [composable authoring](../docs/composable_authoring.md) maps changes to checks. [Visualization guide](../docs/visualization_guide.md) owns the project-output review recipe. Structural/source gates, decoded images, native PDF-log checks and final-size human inspection are distinct evidence; none alone certifies scientific completeness, all-CVD safety, print acceptance or remote publication.
