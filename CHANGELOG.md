- Mutation rates are an unsorted `MutationRateEvidence` / `MUTATION_RATE_EVIDENCE` source catalog, with explicit target, organism, time basis and ascertainment, not a ranked burden spectrum. `mutation_rate_spectrum()` returns that catalog.
- Macromolecule tiers use `building_blocks`, `molecule` and `is_polymer`; lipid assemblies are not polymers.
- Transpiration takes `internal_vapor_mole_fraction` and `external_vapor_mole_fraction` (mol/mol), multiplied by conductance in mol m^-2 s^-1.
- Mermaid rendering takes `size=1200`, `square=True`; the project diagram CLI uses `--size`, not width/height aliases. Mermaid CLI is locked to 12.2.0.
- Template integration accepts only `BIOLOGY_TEXTBOOK_TEMPLATE_ROOT` or a genuine enclosing template; invalid explicit roots fail. Local imports win. Use project-local `scripts/render_textbook.py`, never template-root recipes.
- Assessment synchronization preserves curated semantic mappings and rubrics. Unsupported answer generation refuses without writing; required labs are finite printed-data packets.
- Existing explicit count/container guards distinguish invalid-type `TypeError` from numeric-domain `ValueError`; no blanket new validators. Curriculum implementation imports use lowercase `unit_i`–`unit_x`; authored IDs remain unchanged. Marine precipitation metadata is `None`, not a terrestrial zero.
- Removed automatic lab/question body synchronization, obsolete ownership markers and report fields; native repeated CLI runs preserve authored assessment bytes, mtimes and inodes. Canonical heading/navigation maintenance remains supported.
- `biology.citations.bib_keys()` raises `ValueError` on duplicate document keys. Invalid-bibliography consumers retain explicit failure and continue independent diagnostics rather than claiming an empty valid source set.
- Removed the obsolete `chapter_badges.build_grid` alias; use `build_course_planning_grid`. Grid regeneration preserves authored prefixes/suffixes, does not duplicate page breaks, and is byte/mtime/inode-stable on repeated application.
- `run_pdf_log_check` and its CLI now inherit the horizontal overflow budget when no separate vertical budget is supplied, matching the parser. Native publication therefore enforces 50 points in both directions instead of silently allowing 350 vertical points; explicit vertical overrides remain supported.

### Scientific corrections and limits

- CpG maintenance follows `f_next = f*(1+p)/2`.
- ATP accounting is oxidative 26 plus substrate-level 4 = 30, with shuttle adjustment already included. Glycolysis reaction energies include multiplicity: approximately -73.97 kJ/mol glucose under standard conditions, not cellular conditions.
- GHK is limited to monovalent ions. Numerical APIs enforce finite domains and stable evaluations; insufficient explicit-Euler resolution is rejected.
- SIR conserves population, pollen saturation is exact and finite, bacterial stationary phase is continuous, and Hodgkin–Huxley updates use a simultaneous prior state.
- The isolation ratio `mu/(mu+m)` remains an unvalidated heuristic; the Hebbian rule is not BCM, and Lotka–Volterra is predator–prey, not competition.
- Synthetic teaching outputs are distinguished from observations; citation metadata intake does not establish full-text verification. Current-claim and content-repair evidence records retain source limits.
- GHK prose, arithmetic and figure now share the selected 310-K ion concentrations and computed reference −72.5 mV. Synaptotagmin family descriptions distinguish calcium-sensitive and insensitive members.
- Energy charge does not uniquely specify nucleotide composition, AMPK activity or ATP-hydrolysis free energy. New examples explicitly construct equal-EC pools and a phosphate perturbation; synthetic MCA data illustrate local coefficients, not measured universal control fractions.
- Metformin mechanism is separated from AMPK dependence using the cited mouse knockout experiments. Drug/pathway observations do not establish human efficacy, longevity or a bistable signaling switch; related questions now require discriminating controls.
- Site-specific insulin signaling is not reduced to an inhibitory IRS-1 serine rule: the cited mouse Irs1 Ser307 knock-in counterexample distinguishes organism, residue numbering, preparation and outcome.
