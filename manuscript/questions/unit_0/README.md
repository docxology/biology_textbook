# Unit 0 Question Banks

Three 30-item question banks for Unit 0 chapters.

These files follow the shared question-bank contract in [`../README.md`](../README.md): one `questions_<chapter_stem>.md` per chapter, a generated H1 and `sec:q_unit_0_<stem>` label, a parent-chapter `\cref{}` link, 30 solution blocks, and item-level assessment metadata.
