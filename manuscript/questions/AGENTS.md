# `manuscript/questions/` — AGENTS.md

## Role

Question banks that accompany the textbook, one per chapter. **38 question banks** total, **30 questions each** (10 recall + 10 application + 10 synthesis), organised into 11 unit subdirectories (`unit_0/` through `unit_X/`). Rendered as an appendix when `appendices.include_questions: true` in `manuscript/config.yaml`.

## File Names and Mapping

```
questions/unit_<X>/questions_<chapter_stem>.md
```

- `<X>` is the unit id from `config.yaml`
- `<chapter_stem>` matches the parent chapter's filename (without `.md`). For example, `manuscript/unit_IV/gene_expression.md` → `manuscript/questions/unit_IV/questions_gene_expression.md`.

Every question-bank file is registered in `manuscript/config.yaml` under
`appendices.questions[]`. Store only the `file:` entry there; `src/biology/toc.py`
derives the rendered question-bank title from the parent chapter title.
Item-level assessment comments are maintained by `../../scripts/sync_assessment_metadata.py`
and parsed by `src/biology/assessment.py`; do not remove them when editing prose.

## Required structural elements

Every question-bank file **must** contain:

1. **H1 title** — generated by `../../scripts/sync_curriculum_materials.py`, e.g. `# Questions — Ch 13: Gene Expression — Transcription and Translation`
2. **Section label** — `\label{sec:q_unit_X_<stem>}` on the line after the H1 (inserted by `../../scripts/insert_crossref_labels.py`)
3. **Parent-chapter back-link** — one sentence near the opening using cleveref:

   ```markdown
   *This activity accompanies \cref{sec:unit_X_<stem>} of the textbook — review that chapter before attempting the exercises below.*
   ```

   (Inserted by `../../scripts/link_labs_to_chapters.py`.) The presence of this back-link is enforced by `tests/test_build_invariants.py::test_every_question_links_to_parent_chapter`.

4. **Exactly 30 questions** in three tiers:
   - Questions 1–10: recall & comprehension (Remember, Understand)
   - Questions 11–20: application & analysis (Apply, Analyse)
   - Questions 21–30: synthesis & evaluation (Evaluate, Create)

## Student vs instructor edition

`manuscript/config.yaml → export.include_solutions` controls whether answer keys are rendered:

- `false` (default): **student edition** — questions only
- `true`: **instructor edition** — include answer keys / worked solutions

Write answer material inside `<!-- SOLUTION` / `SOLUTION -->` blocks so it renders cleanly either way:

```markdown
## Q1. Recall

State Mendel's two laws and give the biological basis for each in terms of meiosis.

<!-- SOLUTION
Answer: (1) Law of segregation — allele pairs separate during gamete formation
(basis: homolog separation in meiosis I). (2) Law of independent assortment —
non-linked genes assort independently (basis: random orientation of bivalents
at metaphase I). Modern synthesis refines: linked genes assort together, and
independent assortment applies to loci on different chromosomes or those
separated by > ~50 cM.
SOLUTION -->
```

The analysis injector leaves these HTML comments hidden in the student edition and reveals them as blockquoted answers when `include_solutions: true`.

## Cross-references

- Refer to textbook sections with `\cref{sec:unit_X_<stem>}`
- Refer to figures with `\cref{fig:unit_X_<descriptor>}`
- Refer to BibTeX entries with `\citep{…}` / `\citet{…}` when questions cite landmark papers

## Adding a new question bank

1. Create `manuscript/questions/unit_<X>/questions_<stem>.md` (copy an existing file as a template)
2. Register it in `manuscript/config.yaml` under `appendices.questions[].files[]` with only `file: questions_<stem>.md`
3. Run `../../scripts/insert_crossref_labels.py` (adds `\label{sec:q_unit_X_<stem>}`)
4. Run `../../scripts/link_labs_to_chapters.py` (adds the `\cref{}` back-link)
5. Run `../../scripts/sync_curriculum_materials.py` (normalizes the question-bank H1 from `biology.toc`)
6. Ensure exactly 30 questions across the 10 / 10 / 10 tiers
7. Run `../../scripts/sync_assessment_metadata.py --check`
8. Verify: `uv run pytest ../../tests/test_toc_consistency.py ../../tests/test_build_invariants.py ../../tests/test_assessment_metadata.py -v`

## Quality checklist

- [ ] Exactly 30 questions
- [ ] Exactly 30 solution blocks, one per question, inside `<!-- SOLUTION ... SOLUTION -->`
- [ ] Tier boundaries preserved (questions 1–10 vs 11–20 vs 21–30)
- [ ] Questions 21–30 include at least one reference to a landmark paper via `\citep{…}` / `\citet{…}`
- [ ] No mock data — computational questions use real numerical inputs tractable by mental arithmetic or a simple calculator
- [ ] Open-ended synthesis answers include the mechanism/model, evidence or data cue, scoring expectation, common pitfall, and parent-chapter `\cref{...}`
- [ ] No generated answer scaffolds remain (`Expected reasoning:`, `A complete response should`, `Required clauses:`, or generic "build a mechanistic answer" language)
- [ ] Optional `<!-- LO:... -->` comments map representative questions to parent-chapter learning objectives
- [ ] `uv run python scripts/refine_generated_answers.py --dry-run` reports `refined=0`
