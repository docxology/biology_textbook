# Unit IV Question Banks

Four 30-item question banks for Unit IV chapters.

These files follow the shared question-bank contract in [`../README.md`](../README.md): one `questions_<chapter_stem>.md` per chapter, a generated H1 and `sec:q_unit_IV_<stem>` label, a parent-chapter `\cref{}` link, 30 solution blocks, and item-level assessment metadata.
