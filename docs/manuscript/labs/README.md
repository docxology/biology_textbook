# Paper-Based Biology Labs

The configured 44 labs accompany the 44 core chapters, including Unit 0. Required work uses finite printed datasets, image/card packets, calculators, graphs, comparisons, and uncertainty reasoning. Material-handling or specialized-equipment variants are optional, not prerequisites.

## Find and use a lab

Each unit contains `lab_<chapter_stem>.md`. Follow its parent-chapter link, learning objectives, materials/data packet, procedure, recording tables, analysis, and safety/ethics. Blank recording cells are intentional student workspace. Data provenance and synthetic assumptions must be explicit.

Lab inclusion and order come from `../config.yaml` (`appendices.include_labs` and `appendices.labs`). An unnumbered lab carries its stable Pandoc H1 identifier; chapter backlinks remain numbered semantic references. The configured compact page layout does not guarantee that a particular printer can image the margins: inspect actual pages and allow writing space.

Authoring, semantic assessment metadata, references, and validation are owned by [AGENTS.md](AGENTS.md). Figure workflows are owned by [the visualization guide](../../visualization_guide.md); do not install or run a template-root environment for this standalone project.
