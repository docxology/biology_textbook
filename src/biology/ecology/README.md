Public surfaces include `Species`, `PopulationGrowthResult`, `LotkaVolterraResult`, `BiodiversityResult`, `exponential_growth`, `logistic_growth`, `allee_strong_growth`, `lotka_volterra`, `food_web_trophic_levels`, `connectance`, `species_area_relationship`, and `biodiversity_indices`.
