# Foundational Biology Models and Reference Tables

Helpers support Unit 0 systems/model interpretation and Unit I chemical/macromolecular foundations. They include authored milestone dates, bonding and molecule tables, network-degree distributions, and explicitly limited prediction/precision teaching models.

A truncated degree distribution is not a generated biological network; a precision-weighted error calculation is not a calibrated neural circuit; selected milestone dates do not certify historical completeness. State the model and reference-table limits when using outputs in prose or figures.

[AGENTS.md](AGENTS.md) maps modules and consumers. [The API reference](../../../docs/api_reference.md#biologyfoundations) owns callable examples, and [the visualization guide](../../../docs/visualization_guide.md) owns figure generation.
