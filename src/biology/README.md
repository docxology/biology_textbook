# Biology Package

Domain computation and manuscript metadata live here. The package has nine domain subpackages plus utilities for table-of-contents resolution, chapter metadata, curriculum alignment, current-claim validation, assessment metadata, and cross-reference scanning.

## Layout

| Path | Role |
| ---- | ---- |
| `biochemistry/` | Enzyme kinetics, free energy, ATP, glycolysis summaries |
| `botany/` | Water potential, transpiration, photosynthesis, plant growth |
| `cell/` | Organelles, membrane potentials, transport, signaling |
| `ecology/` | Population growth, Lotka-Volterra, food webs, diversity |
| `evolution/` | Selection, drift, fitness landscapes, isolation, molecular clocks |
| `genetics/` | DNA/RNA, translation, crosses, Hardy-Weinberg, linkage, epigenetic helpers |
| `microbiology/` | Growth curves, MIC, SIR dynamics, reference organisms |
| `neuroscience/` | Hodgkin-Huxley, passive cable, synaptic current, Hebbian updates |
| `physiology/` | Blood flow, oxygen saturation, homeostasis |

Use `../README.md` for source-tree navigation and `../../docs/api_reference.md` for the curated public API.
