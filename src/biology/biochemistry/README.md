# Biochemistry Package

Quantitative helpers for Unit I chemistry and Unit III metabolism.

Public surfaces include `EnzymeKineticsResult`, `GlycolysisResult`, `michaelis_menten`, `competitive_inhibition`, `enzyme_rate_curve`, `reaction_free_energy`, `atp_free_energy`, and `glycolysis_summary`.

Use these functions from chapters, labs, and optional computation snippets instead of reimplementing formulas in scripts.
