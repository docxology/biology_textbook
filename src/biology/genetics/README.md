# Genetics Package

Molecular, classical, population, linkage, and epigenetic helpers for Units IV and V.

Public surfaces include `DiploidGenotype`, `PunnettSquareResult`, `HardyWeinbergResult`, `ChiSquaredResult`, `LinkageMapResult`, `dna_complement`, `transcribe_dna_to_mrna`, `translate_mrna`, `gc_content`, `punnett_square`, `hardy_weinberg`, `chi_squared_test`, `hamming_distance`, `recombination_frequency`, `genetic_distance`, `infer_three_point_order`, `jukes_cantor_distance`, `cpg_methylation_remaining`, and `histone_modification_state`.
